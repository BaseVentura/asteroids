# Asteroids

A Python implementation of the classic Asteroids arcade game.

## About

This project is a recreation of the iconic Asteroids arcade game, featuring the core gameplay mechanics of the original with modern Python implementation. This is a learning project.

## Features

- Classic Asteroids gameplay
- Python-based implementation
- Arcade-style mechanics

## Installation

Clone the repository:

```bash
git clone https://github.com/BaseVentura/asteroids.git
cd asteroids
```

Install dependencies (if any):

```bash
pip install -r requirements.txt
```

## Usage

Run the game:

```bash
python asteroids.py
```

## Requirements

- Python 3.x
